# 板子库

ICPC / CCPC 竞赛用的 C++ 算法模板库：123 个模板文件按主题分目录，配套一份可打印的 LaTeX 讲义（`板子库.pdf`）。

作者：mortal

## 目录结构

| 目录 | 文件数 | 内容 |
| --- | --- | --- |
| `dp/` | 6 | 状压、数位、单调队列、斜率、前缀和、线段树优化 |
| `图论/` | 46 | 网络流与上下界流、二分图、连通性（tarjan / 点双 / 边双 / 圆方树）、生成树、最短路、2-SAT |
| `字符串/` | 10 | KMP、exKMP、SA、SAM、PAM、ACAM、trie、hash、马拉车、最小表示法 |
| `数学/` | 14 | 线性筛、CRT、exgcd、BSGS、杜教筛、Pollard Rho、矩阵、高精度、拉格朗日插值、整除分块、poly |
| `数据结构/` | 33 | 线段树家族、平衡树（Splay / Treap）、LCT、树剖、并查集、莫队、分块、线性基、可持久化 |
| `杂项/` | 9 | 对拍、快读快输、CDQ 分治、wqs 二分、IDA\*、康托展开、随机哈希、多进程 |
| `计算几何/` | 7 | 凸包、半平面交、旋转卡壳、平面最近点对、三维凸包、三角剖分、基础定义 |
| `doc_tmp/` | 2 | 分治求和、莫比乌斯反演的推导稿（PDF） |
